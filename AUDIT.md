## 2. How it was tested

`tests/audit.spec.ts` (config: `playwright.config.ts`), run against the production build (`npm run build`, then `astro preview` on port 4400; the project has no `npm start`). 61 pages × 8 projects = 488 runs, 13 min: desktop Chrome 1920×1080, Firefox, Safari (WebKit); iPhone 14 (WebKit), Pixel 7, Galaxy S9+; iPad Mini portrait and landscape. Per page: console errors, failed requests, control bar on one row, horizontal overflow, CLS (Chromium only), an option click, ArrowRight colour change and the F shortcut (desktop), Fullscreen button + fallback + wake lock + Escape, a tap on the stage, timers ticking, a rotation (phones/tablets), dark mode + reduced motion.

Re-run only failures: `npx playwright test --last-failed`. Raw per-run findings: `tests/out/issues/*.json`.

Not counted as site bugs (third-party, seen on most runs): Microsoft Clarity and Bing beacons failing or blocked, AdSense/DoubleClick iframes logging cross-origin "Blocked a frame" errors, reCAPTCHA report-only CSP notices, and `/api/rating` 404s (serverless functions don't run in `astro preview`).
